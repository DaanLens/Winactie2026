# LENS AI winactie

Deelnemers schrijven zich in, slaan ballen in de emmers en vullen hun score in met de standcode. De top 5 staat live op het scorebord.

- `index.html`: inschrijven en score invullen
- `scorebord.html`: live top 5 voor een groot scherm
- `beheer.html`: deelnemers, winnaars, CSV-export en instellingen
- `supabase/schema.sql`: database en functies

Publiceren gaat automatisch bij elke push naar `main`.

    npm install
    npm run dev
